خطة تجربة صغيرة قابلة للقياس

التسجيل والمراجعة

  1. اختر آية قصيرة في رواية حفص، وسجّل في مكان هادئ دون صوت قارئ في الخلفية.
  2. اجمع ١٢ مقطعًا على الأقل: ٤ صحيحة، و٤ فيها خطأ حركة، و٤ فيها خطأ شدّة. يحدد الخطأ المقصود بإشراف المعلّمة؛ ولا تعتمد النية وحدها كتقييم.
  3. استمعي لكل تسجيل دون الاطلاع على ناتج النموذج أولًا، واضغطي كل كلمة وسجّلي الصحيح أو الخطأ أو غير المحسوم. اكتبي ما سمعته وشرح التصحيح واسمًا أو رمزًا للمراجِعة.
  4. نزّل نسخة التجربة لحفظ التسجيلات والملاحظات. لا ترسلها لأي خدمة إلا بعد اختيارها ومراجعة سياسة التعامل مع الصوت.
  5. عند توفر خدمة التحليل، حلّل المقاطع نفسها، وحمّل النتائج لكل تسجيل. راجع التنبيهات الخاطئة والأخطاء الفائتة قبل اعتماد الخدمة.
  6. بعد ضبط حد الثقة، اختبر تسجيلات جديدة لم تُستخدم لضبطه، ويفضل بأصوات مختلفة. هذه تجربة أولية وليست إثباتًا لدقة عامة.

ما الذي يمكن تنفيذه الآن؟

التسجيل والحفظ المحلي ومراجعة الكلمات والتصدير واستيراد النتائج والتقرير تعمل دون خدمة تحليل. لا يوجد نموذج متصل، ولا توجد تسجيلات أو تقييمات بشرية جاهزة. لا يمكن تحديد «ما نطقته» تلقائيًا قبل تحليل الصوت.

الصحيح المعروض يأتي من نص الآية. التشغيل المرجعي للآية كاملة؛ لا ندّعي تحديد توقيت كل كلمة داخل التسجيل. يُضاف قصّ الكلمة عندما يوفر المحلّل توقيتًا موثوقًا أو تراجعه المعلّمة.

صيغة نتيجة التحليل

هذه صيغة تبادل خاصة بالتجربة، وليست واجهة جاهزة لأي مزود. يحتاج المزود إلى محوّل لهذه الصيغة. لا تستخرج الحركات المسموعة من نص الإملاء أو تخمّنها من المرجع. استخدم null للثقة غير المتاحة. إذا لم يُرجع المحلّل قياس ثقة يمكن التحقق منه، تبقى النتيجة غير محسومة.

{
  "version": 1,
  "sampleId": "recording identifier from exported sample",
  "audioSha256": "SHA-256 from exported sample",
  "reference": "exact reference from exported sample",
  "provider": "analyzer name and version",
  "words": [
    {
      "index": 0,
      "status": "uncertain",
      "confidence": null
    }
  ]
}

ترقيم الكلمات يبدأ من صفر ويطابق مصفوفة words في نسخة التجربة. الحالات: correct وerror وuncertain. الخطأ يحتاج type من vowel أو shadda أو letter أو missing أو tajweed، وحقل heard للنطق المرصود وexplanation للشرح. تُرفض النتائج غير المطابقة لبصمة الصوت أو نص الآية.

كيف نقرأ التقرير؟

دقة التنبيهات = الأخطاء الحقيقية بين الكلمات التي نبّه إليها النموذج. استرجاع الأخطاء = الأخطاء التي التقطها من الأخطاء التي أكدتها المعلّمة. تُحسب الأخطاء غير المحسومة كأخطاء لم يلتقطها المحلّل عند وجود نتيجة له. التغطية = الكلمات ذات الحكم الآلي المحسوم من الكلمات المراجَعة. «—» تعني عدم وجود بيانات تكفي للحساب، وليست صفرًا أو مئة بالمئة.

اللون الأخضر والأحمر في صفحة التجربة يعبّران عن تقييم المعلّمة، والحد المتقطع يعني عدم المراجعة أو عدم الحسم. لا توجد نسبة دقة فعلية قبل تسجيل عينات ومراجعتها وتحليلها.
